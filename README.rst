Automated integration test runner for Invenio modules.

Invenio-Testrig eliminates the fear of breaking InvenioRDM repositories with
your contributions. It allows you to test your changes across your contribution,
affected packages, and inside a running repository in a safe and automated way,
either on GitHub or locally.

Further documentation is available on
https://invenio-testrig.readthedocs.io/
